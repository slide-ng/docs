# Credits

slide.ng is not a fork of *Slidev, but it stands on it. It uses Slidev's published markdown parser, `@slidev/parser`, and ports its click logic. The file format, the layout names, many frontmatter keys and the documentation structure follow Slidev. Slidev is MIT licensed, copyright (c) 2021 Slidev.js Team.

The four official themes are rebuilt from the official Slidev themes: `seriph` by Anthony Fu, `shibainu` and `bricks` by iiiiiiinès, and `apple-basic` by Jeremy Meissner. The layouts, slots, CSS values and font settings are ported, the Angular components are new code, and the images, which are CC BY-NC-SA 4.0, are not used. See the [Theme gallery](../customize/theme-gallery.md).

slide.ng is built on *Angular, with *Shiki, *KaTeX, *Mermaid, *Monaco and *UnoCSS, and draws with `drauu` and `rough-notation`.

This documentation is made with *NgMd. The pictures of layouts and of the interface are screenshots of slide.ng's own test decks.
