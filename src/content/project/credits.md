# Credits

slide.ng is not a fork of *Slidev, but it stands on it. It uses Slidev's published markdown parser, `@slidev/parser`, and ports its click logic. The file format, the layout names, many frontmatter keys and the documentation structure follow Slidev. Slidev is MIT licensed, copyright (c) 2021 Slidev.js Team.

Four of the official themes are rebuilt from the official Slidev themes: `seriph` by Anthony Fu, `shibainu` and `bricks` by iiiiiiinès, and `apple-basic` by Jeremy Meissner. The layouts, slots, CSS values and font settings are ported, the Angular components are new code, and the images, which are CC BY-NC-SA 4.0, are not used. The fifth, `adev`, is inspired by angular.dev (Angular, MIT, Google LLC) and is not an official Angular theme; slide.ng is not affiliated with or endorsed by Google or the Angular team. See the [Theme gallery](../customize/theme-gallery.md).

slide.ng is built on *Angular, with *Shiki, *KaTeX, *Mermaid, *Monaco and *UnoCSS, and draws with `drauu` and `rough-notation`.

The cover of the demo on the home page shows the Angular logo, drawn in one flat colour. The logo is by Google LLC and the Angular team, from the [Angular press kit](https://angular.dev/press-kit), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). It was changed: the gradient was removed and the colour set to the slide.ng orange. This is not an endorsement by Google or the Angular team. Angular is a trademark of Google LLC.

This documentation is made with *NgMd. The pictures of layouts and of the interface are screenshots of slide.ng's own test decks.
