# Code groups

Wrap blocks in `::code-group` and `::`. The tab name is the title in brackets.

`````md
::code-group

```sh [npm]
npm i slide-ng
```

```sh [yarn]
yarn add slide-ng
```

::
`````

The `~icon~` title syntax and the automatic file icons of Slidev are not drawn.
