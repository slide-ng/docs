# Transform

`<transform>` scales what is inside it.

```md
<transform scale="0.5" origin="top left">

![](/photo.png)

</transform>
```

`scale` is a number and `origin` is a CSS `transform-origin`. Leave empty lines inside the tag if you want markdown inside to be converted. See also [Zoom](./zoom.md) for a whole slide.
